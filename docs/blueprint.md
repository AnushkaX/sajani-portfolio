# **App Name**: AtelierFlow

## Core Features:

- Hero Section: Landing page with a hero section showcasing the designer's name, tagline, and a clear call-to-action to view the portfolio. Features a full-screen background or carousel with featured work.
- About Me: An 'About Me' section displaying a short biography with a profile photo and the designer's design philosophy or inspiration.
- Portfolio Gallery: Interactive portfolio gallery with grid/masonry layout, showcasing fashion design works with categories like 'Casual', 'Haute Couture', 'Sketches'.
- Project Details: Detailed project pages or modals with title, description, date, and multiple images or embedded video content. Each item links to a detail view (modal or dedicated route)
- Resume/CV: Display a link to download resume/CV in PDF format. Provide key sections directly on the website to allow easy viewing of education, experience, and skills.
- Contact Form: A contact section with a contact form and social media links, including a name field, email, and message, plus links to designer's social profiles (Instagram, LinkedIn, Behance).

## Style Guidelines:

- Primary color: A subdued lavender (#B5A2DD) evoking creativity and elegance.
- Background color: Very light grey (#F0F0F0), promoting focus on the designs.
- Accent color: A slightly brighter, complementary purple (#D2B4DE) is used for interactive elements and highlights.
- Font: 'Belleza' sans-serif for headlines and short chunks of text; 'Alegreya' serif for body text. Belleza will convey personality related to fashion, art and design; and Alegreya is perfectly suitable for body text.
- Mobile-first design with a clean and minimalistic layout to highlight the visual content. CSS grid and flexbox used for responsive scaling across different devices.
- Smooth reveal animations when scrolling to various sections. Hover effects on images to add interactivity and engagement.
- Simple, modern icons used for navigation and social media links. Consistent style throughout the site to maintain visual coherence.
